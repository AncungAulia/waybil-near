# Flags

Country flags for the phone code picker, one `<iso2>.svg` per country, loaded only when shown.

- `id`, `my`, `ph`, `sg`, `th`, `us` and `vn` were drawn for the Waybil design.
- Every other flag comes from
  [country-flag-icons](https://gitlab.com/catamphetamine/country-flag-icons) 1.5.19 (3x2),
